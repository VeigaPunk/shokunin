## A round (mechanics from the addendum; session additions)

1. `inline.sh dispatch <lane>`, then one L1 `task` with no model parameter. Its prompt says:
   execute `.ufo/prompts/<lane>-round-<N>.md`. Add a session note of ≤10 lines: order position,
   repair-first if the previous closure was rejected, routed sibling sources, and the time budget.
2. **Time budget.** At 2 h, message the L1: "freeze scope; land what verifies; file an honest
   report." At 3 h with no landed report, give it 20 min more. Then cancel the job, run
   `inline.sh fail`, and move the lane to the back of the order. (ROUND_MAXTIME in hyaku.env is
   170m; the note is the enforcement.)
3. Then: `inline.sh verify`, then `inline.sh closure`, then a **fresh** closure `task` (never the
   L1, never resumed), then `inline.sh closed`, then `inline.sh advance`. Dispatch closures as soon
   as their round lands, in parallel with other lanes' rounds.
4. Each lane-round gets ≤2 attempts this session. Each closure gets ≤1 re-dispatch.

## Quality bar

- **Learning claim.** Each round must have ≥1 claim that changes what the lane knows or can do in
  its PROVINCE core or frontier: admitted knowledge on uncovered ground; a stronger entry
  superseding a weaker one; a SKILL.md decision table or error pattern grounded in admitted
  entries; or a capability shown running and entered in SCORECARD's capability table. Gates,
  ledgers and tooling count only when they are the lane's own province and ran this round.
- **Claim sizing** (fleet lesson):
  - Declare each after-state as one concrete value the closure can re-derive with one command over
    committed bytes. Size it to what one round can land and verify.
  - No universal clauses ("all", "complete", "every", "no harm anywhere") unless the counting
    command enumerates the full set.
  - A calibration claim must count mismatches between self-assessment and observed repo state.
  - Prefer 2 claims. A 3rd only if independent and cheap to verify.
  - Never narrow a target after landing: a miss is an honest stop.
  - A target must be one a do-nothing control cannot reach. Freeze one predicate that is the same
    sentence in the plan, the same condition in the counter's code and the same label in the
    receipt.
- **Sources.** Primary sources, opened this round, each with a located quote. ≥25% of each round's
  seats attack (reviewer, critic, mutation-tester, labrat). Executors only for code. Scribes for
  prose.
